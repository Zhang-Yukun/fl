# 结果输出与配置字段说明

本文档覆盖三类内容：

1. 运行配置中的关键字段及含义。
2. 实验输出目录中各类结果文件的字段定义。
3. wandb 标量与可视化字段的命名规则。

本文档以当前代码实现为准，不再描述已移除的兼容别名。

## 1. 命名约定

### 1.1 参数通信量 vs 真实传输量

- `parameter_*`：算法语义层面的参数通信量。只统计为了让接收方恢复聚合语义而必须发送的参数内容，包括量化比例、稀疏索引、编码上下文等算法必需信息。
- `transport_*`：实际传输层字节数。等于序列化后在单节点/多节点协议里真实发送的总字节数，包含协议和序列化开销。
- `*_compression_ratio` / `*_communication_ratio`：分母是当前算法，分子是同轮 FedAvg 稠密基线，因此值越大表示越省通信。

### 1.2 协议路径 vs Oracle 路径

- `protocol_*`：严格使用协议路径中真正传输、真正恢复后的状态做验证/测试。
- `oracle_*`：只用于评测。服务器用未压缩、未失真的精确更新构造理想状态做验证/测试，不参与真实训练闭环。
- `active_*`：当前实验真正用于早停、最佳轮选择和最终 `test` 输出的那条评测路径，由 `evaluation.mode` 控制。

### 1.3 攻击指标命名

- `primary_metric_name`：当前攻击主指标名称。
- `primary_metric_value`：该主指标的数值。
- `objective_mse`：攻击优化时拟合被截获梯度/更新量的目标函数值，不等于输入重构误差。
- `nearest_client_train_mse`：重构输入与“被攻击客户端完整训练集里最近样本”的 MSE。
- `exact_target_mse`：重构输入与真实攻击样本的 MSE。对 `update_payload` 默认不输出，只有显式配置才输出。

## 2. 配置字段

### 2.1 通用配置

#### `experiment`

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `name` | string | 实验名称。 |
| `mode` | string | `centralized` 或 `federated`。 |
| `output_dir` | string | 输出目录。 |

#### `runtime`

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `device` | string | 训练与默认攻击设备，例如 `cpu`、`cuda:0`。 |
| `log_level` | string | loguru 日志等级。 |
| `deterministic` | bool | 是否启用确定性 torch 运行设置。 |
| `seed` | int, optional | 全局随机种子。 |

#### `task`

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `type` | string | 当前任务类型；现有时序任务通常为 `forecasting`。 |

#### `data`

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `csv_path` | string | 原始汇总 CSV 路径。某些数据构建流程会被客户端/服务器切分后的 CSV 覆盖。 |
| `clients` | list[string] | 客户端名称列表。 |
| `seq_len` | int | 输入窗口长度。 |
| `pred_len` | int | 预测窗口长度。 |
| `batch_size` | int | DataLoader batch size。 |
| `shuffle_train` | bool | 训练集 DataLoader 是否打乱。关闭后可配合种子保证可复现。 |
| `train_ratio` | float | 自动切分时训练集比例。 |
| `val_ratio` | float | 自动切分时验证集比例。 |
| `num_workers` | int | DataLoader worker 数。 |

#### `model`

该块由具体模型实现解释。当前时序模型常用字段包括：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `name` | string | 模型名称，例如 `patchtst`。 |
| `channels` | int | 输入通道数。 |
| `hidden_size` | int | 隐藏维度；只对对应模型生效。 |
| `dropout` | float | dropout 概率。 |

#### `training`

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `lr` | float | 训练学习率。 |
| `patience` | int | 早停 patience；设为总轮数即可等价于不早停。 |
| `min_delta` | float | 早停最小改进阈值。 |
| `loss` | string | 训练损失；支持 `mse`、`mae`、`smooth_l1`、`huber`、`task_default`。 |
| `smooth_l1_beta` | float | `smooth_l1` 的 beta。 |
| `huber_delta` | float | `huber` 的 delta。 |
| `optimizer` | string | 训练优化器；支持 `adam`、`adamw`、`sgd`。 |
| `optimizer_eps` | float | `adam` / `adamw` 的 eps。 |
| `weight_decay` | float | 权重衰减。 |
| `momentum` | float | `sgd` 动量。 |
| `nesterov` | bool | `sgd` 是否启用 Nesterov。 |

#### `evaluation`

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `mode` | string | `protocol` 或 `oracle`。控制最佳验证轮与最终 `test` 使用哪条评测路径。 |
| `metrics` | list[string] | 额外评测指标名。当前实现始终保证 `mse`、`mae`、`mape` 可用。 |

#### `centralized`

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `rounds` | int | 集中训练总轮数。每轮遍历全部训练数据一次。 |

#### `federated`

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `algorithm` | string | 联邦算法名。 |
| `rounds` | int | 通信轮数。 |
| `local_epochs` | int | 每轮客户端本地 epoch 数。 |
| `local_steps` | int, optional | 若配置则优先按固定 step 数本地训练。 |
| `topk_fraction` | float, optional | Top-k / Random-k / DP-Top-k 等稀疏算法的保留比例。 |
| `randomk_seed` | int, optional | Random-k 类算法随机种子。 |
| `quantization_dtype` | string, optional | 量化类型，例如 `float16`、`qint8`。 |
| `quantization_stochastic_rounding` | bool, optional | 是否使用随机舍入。 |
| `quantization_seed` | int, optional | 量化随机种子。 |
| `qsgd_levels` | int, optional | QSGD 量化级数。 |

当前已接入并保留的联邦算法名：`fedavg`、`adaptive_clipped_rdp_fedavg`、`sparse_fedavg`、`randomk_fedavg`、`sign_fedavg`、`qsgd_fedavg`、`secure_quantized_fedavg`、`ega_fedavg`。集中训练模式使用单独的 `centralized` 入口。

#### `transport`

输出结果中不再单独记录 `upload_mode` / `download_mode`，因为协议已固定为“上传 `update`、下发 `model`”。

#### `attack`

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `enabled` | bool | 是否启用攻击。 |
| `target_type` | string | 攻击目标；当前仅支持 `update_payload`。 |
| `reference_metric` | string | 兼容旧字段，用于控制是否暴露 `reconstruction_mse` 或 `nearest_client_train_mse` 口径。 |
| `report_metrics` | list[string] | 附加输出的参考指标列表；默认 `auto` 仅保留 `nearest_client_train_mse`。 |
| `steps` | int | 单次攻击优化迭代步数。 |
| `lr` | float | 攻击优化学习率。 |
| `optimizer` | string | 攻击优化器；当前仅支持 `adam`。 |
| `restarts` | int | 攻击随机重启次数。 |
| `input_clip` | float, optional | 攻击过程中对 dummy x 的裁剪上界。 |
| `target_clip` | float, optional | DLG 时对 dummy y 的裁剪上界。 |
| `tv_weight` | float, optional | 输入总变分正则权重。 |
| `seed` | int, optional | 攻击随机种子。 |
| `recovery_match_metric` | string | 构造样本匹配矩阵时使用的指标；支持 `mse`、`psnr`、`ssim`。 |
| `recovery_match_objective` | string | 匹配时目标方向；`auto`、`min`、`max`。 |
| `recovery_success_metric` | string | 判定样本是否恢复成功的指标；支持 `mse`、`psnr`、`ssim`。 |
| `recovery_success_objective` | string | 成功判定方向；`auto`、`min`、`max`。 |
| `recovery_success_threshold` | float, optional | 恢复成功阈值；未设置时按所选成功指标默认值推导。 |
| `success_mse_threshold` | float | MSE 口径默认阈值，也作为默认恢复阈值推导来源。 |
| `success_ssim_threshold` | float, optional | SSIM 口径默认阈值，也作为默认恢复阈值推导来源。 |
| `success_rate_threshold` | float | 汇总统计里整体是否通过的成功率阈值。 |
| `data_range` | float | 计算 PSNR / SSIM 时使用的数据范围。 |
| `client_selection` | string | 被攻击客户端选择策略：`all`、`first`、`round_robin`。 |
| `clients_per_round` | int | 每个被攻击轮次选择多少个客户端。 |
| `frequency_rounds` | int | 每隔多少通信轮做一次攻击。 |
| `sample_count` | string or int | 每个被攻击客户端在该轮发起多少次独立攻击；`auto` 时当前默认取 `1`。 |
| `max_samples` | string or int | 单次攻击评估中联合重构多少条样本；`auto` 时取客户端训练样本数。 |
| `max_samples_cap` | int | `max_samples=auto` 时的样本数上限。 |
| `model_mode` | string | 攻击模型使用 `train` 还是 `eval` 模式。 |
| `local_optimizer` | string | `update_payload` 近似本地更新时假设的客户端优化器。 |
| `local_lr` | float | `update_payload` 攻击里假设的客户端本地学习率。 |
| `local_optimizer_eps` | float | `update_payload` 攻击里假设的 Adam eps。 |
| `async_enabled` | bool | 是否异步执行攻击。 |
| `async_workers` | int | 异步攻击 worker 数。 |
| `async_max_pending_rounds` | int | 异步攻击最多积压多少轮。 |
| `device` | string | 攻击设备；`same` 表示继承 `runtime.device`。 |

### 2.2 算法专用配置块

#### `privacy`

仅 DP / 安全相关方法使用。常见字段：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `clip_norm` | float | 更新裁剪范数。 |
| `noise_multiplier` | float | 高斯噪声系数。 |
| `delta` | float | DP delta。 |

#### `adaptive_clipped_rdp`

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `initial_clip_norm` | float | 初始裁剪阈值。 |
| `target_quantile` | float | 自适应裁剪目标分位数。 |
| `learning_rate` | float | 裁剪阈值更新步长。 |
| `noise_multiplier` | float | 追加噪声强度。 |
| `delta` | float | DP delta。 |
| `seed` | int | 随机种子。 |

#### `ega`

EGA 专用编码与预训练配置，字段较多。建议以实际 `configs/*ega*.yaml` 为准。常见字段包括编码维度、码本大小、量化位宽、预训练轮数、预训练学习率、上下文统计方式等。

## 3. 输出目录文件

### 3.1 公共文件

| 文件 | 说明 |
| --- | --- |

### 3.5 `metrics.json`（联邦训练）

`metrics.json` 是 `RoundRecord` 列表。每个元素包含：

#### 轮级字段

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `round` | int | 通信轮索引。 |
| `algorithm` | string | 算法名。 |
| `train_loss` | float | 本轮客户端平均训练损失。 |
| `val_mse` / `val_mae` / `val_mape` | float | 当前 `active_val_scope` 下的验证指标。 |
| `round_time_seconds` | float | 本轮耗时。 |
| `elapsed_time_seconds` | float | 累计耗时。 |
| `model_parameters` | int | 全局模型参数量。 |
| `model_bytes` | int | 全局模型稠密字节数。 |

### 3.6 `attack_results.json`

每个元素对应一次 DLG 或 iDLG 攻击。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `name` | string | 攻击方法名，通常为 `DLG` 或 `iDLG`。 |

| `primary_metric_value` | float or null | 当前主指标值。 |

| `ssim` | float or null | 与精确参考样本相比的 SSIM。 |
| `iterations` | int | 攻击优化步数。 |
| `time_seconds` | float | 单次攻击耗时。 |
| `success` | bool | 该次攻击是否达到当前成功判定规则。 |
| `success_threshold` | float | 当前使用的成功阈值。 |
| `objective_mse` | float | 攻击优化目标值。 |
| `target_type` | string | 当前为 `update_payload`。 |
| `exact_target_mse` | float, optional | 与本次选中真实样本批次的 MSE。 |
| `nearest_client_train_mse` | float, optional | 与被攻击客户端训练集最近样本的 MSE。 |
| `nearest_client_train_indices` | list[int], optional | 最近训练样本索引。 |

| `matched_reference_metric_value` | float, optional | 当前记录匹配后的平均指标值。 |
| `recovered_count` | int, optional | 当前记录中成功恢复的样本数。 |
| `reconstructed_count` | int, optional | 当前记录实际重构的样本数。 |
| `reference_count` | int, optional | 当前客户端参考集合样本数。 |
| `budget_recovered_fraction` | float, optional | `recovered_count / reconstructed_count`。 |
| `coverage_recovered_fraction` | float, optional | `recovered_count / reference_count`。 |
| `client_id` | string | 被攻击客户端。 |
| `round_index` | int | 攻击对应的通信轮。 |
| `sample_index` | int | 本轮该客户端第几次独立攻击评估。 |
| `artifact_path` | string | 对应 `.pt` 攻击张量文件相对路径。 |
| `reference_label` | string | 可视化参考来源，如 `exact_target`、`nearest_client_train`、`matched_client_train`。 |

| 字段 | 含义 |

| `attack/cumulative_avg_primary_metric_value` | 截至当前全部攻击结果主指标平均值。 |
| `attack/cumulative_success_rate` | 截至当前全部攻击结果成功率。 |

#### 按攻击方法

前缀为 `attack/<method>/`，例如 `attack/DLG/`、`attack/iDLG/`：

| 字段 | 含义 |

### 5.2 攻击可视化

| 字段 | 含义 |
| --- | --- |
| `attack/<method>/reconstruction` | 每轮该方法第一条结果的重构图。 |

- 若主指标是 `reconstruction_mse`，图里参考真值就是精确攻击样本。
