# 结果输出文件字段说明

本文档说明一次实验输出目录中的主要结果文件及其字段含义，例如 `outputs/<run_name>/`。

覆盖三类运行模式：
- 集中式训练
- 单进程联邦训练
- 基于 gRPC 的多进程/多节点联邦训练

## 一、输出目录中常见文件

一次典型实验目录下通常会包含以下文件：

- `summary.json`：最终摘要结果，适合做实验对比
- `metrics.json`：训练过程明细
- `attack_results.json`：攻击实验逐条结果，仅在启用攻击时生成
- `config.yaml` / `config.json` / `config.toml`：保存下来的实验配置
- `model.pt`：联邦训练最终全局模型
- `centralized_model.pt`：集中式训练最终模型
- `run.log`：loguru 输出的运行日志
- `client_<client_id>/` 或 `client_<client_id>.log`：gRPC 客户端日志

## 二、各文件整体含义

| 文件 | 含义 | 适用模式 |
| --- | --- | --- |
| `summary.json` | 最终摘要，包含性能、通信、攻击统计 | 集中式 / 联邦 / gRPC |
| `metrics.json` | 训练全过程历史。集中式按 epoch 保存，联邦按 round 保存 | 集中式 / 联邦 / gRPC |
| `attack_results.json` | 每一次 DLG / iDLG 攻击的详细结果 | 联邦 / gRPC 且 `attack.enabled=true` |
| `config.*` | 最终实际生效的实验配置 | 全部 |
| `model.pt` | 联邦训练得到的最终全局模型参数 | 联邦 / gRPC |
| `centralized_model.pt` | 集中式训练得到的最终模型参数 | 集中式 |

## 三、`summary.json`

### 1. 集中式训练下的 `summary.json`

集中式 `summary.json` 包含如下字段：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `test` | object | 最终测试集指标 |
| `test.mse` | float | 测试集均方误差 |
| `test.mae` | float | 测试集平均绝对误差 |
| `test.mape` | float | 测试集平均绝对百分比误差 |
| `epochs` | int | 实际完成的训练轮数 |
| `total_time_seconds` | float | 总训练耗时（秒） |

### 2. 联邦 / gRPC 下的 `summary.json`

联邦模式下，`summary.json` 是最适合做实验最终对比的文件。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `test` | object | 最终全局模型在测试集上的指标 |
| `test.mse` | float | 测试集均方误差 |
| `test.mae` | float | 测试集平均绝对误差 |
| `test.mape` | float | 测试集平均绝对百分比误差 |
| `rounds` | int | 实际完成并记录的联邦轮数 |
| `total_time_seconds` | float | 训练总耗时（秒） |
| `last_upload_compression_ratio` | float | 最后一轮中，FedAvg 基准上传字节数 / 实际参数上传字节数 |
| `last_total_communication_ratio` | float | 最后一轮中，FedAvg 基准总参数通信字节数 / 实际总参数通信字节数 |
| `last_communication_ratio` | float | `last_upload_compression_ratio` 的兼容别名 |
| `last_parameter_upload_bytes` | int | 最后一轮所有客户端参数上传总字节数 |
| `last_parameter_download_bytes` | int | 最后一轮所有客户端参数下载总字节数 |
| `last_parameter_total_bytes` | int | 最后一轮参数上传 + 参数下载总字节数 |
| `last_transport_upload_bytes` | int | 最后一轮所有客户端实际序列化上传总字节数 |
| `last_transport_download_bytes` | int | 最后一轮所有客户端实际序列化下载总字节数 |
| `last_transport_total_bytes` | int | 最后一轮 transport 上传 + 下载总字节数 |
| `last_transport_upload_overhead_bytes` | int | 最后一轮上传中，除纯参数载荷外的额外开销 |
| `last_transport_download_overhead_bytes` | int | 最后一轮下载中，除纯参数载荷外的额外开销 |
| `last_transport_upload_compression_ratio` | float | 最后一轮中，FedAvg 基准上传字节数 / 实际 transport 上传字节数 |
| `last_transport_total_communication_ratio` | float | 最后一轮中，FedAvg 基准总字节数 / 实际 transport 总字节数 |
| `total_parameter_upload_bytes` | int | 全部轮次累计参数上传总字节数 |
| `total_parameter_download_bytes` | int | 全部轮次累计参数下载总字节数 |
| `total_parameter_bytes` | int | 全部轮次累计参数上传 + 下载总字节数 |
| `total_transport_upload_bytes` | int | 全部轮次累计实际序列化上传总字节数 |
| `total_transport_download_bytes` | int | 全部轮次累计实际序列化下载总字节数 |
| `total_transport_bytes` | int | 全部轮次累计实际 transport 总字节数 |
| `total_transport_upload_overhead_bytes` | int | 全部轮次累计上传额外开销 |
| `total_transport_download_overhead_bytes` | int | 全部轮次累计下载额外开销 |
| `attack_target_type` | string | 攻击目标类型，通常为 `gradient` 或 `update_payload` |
| `attack_primary_metric` | string | 本次隐私评估所采用的主指标 |
| `attack_primary_metric_direction` | string | 主指标解释方向，目前为 `higher_is_more_private`，即值越大通常越安全 |
| `attack_overall_avg_mse` | float or null | 所有攻击记录主指标的平均值 |
| `attack_success_rate` | float | 攻击成功率 |
| `attack_evaluations` | int | 攻击记录总条数 |
| `attack_summary` | object | 按攻击方法聚合后的统计摘要 |
| `transport` | string | 仅 gRPC 模式下存在，当前固定为 `grpc` |

### 3. `summary.json` 中的 `attack_summary`

`attack_summary` 是由所有攻击记录聚合得到的摘要。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `primary_metric` | string | 当前实验采用的隐私主指标 |
| `primary_metric_direction` | string | 指标解释方向，当前为“越大越隐私” |
| `target_type` | string or null | 攻击目标类型，通常为 `gradient` 或 `update_payload` |
| `success_rate_threshold` | float | 判定方法是否满足隐私要求所使用的成功率阈值 |
| `overall_avg_mse` | float or null | 所有攻击记录主指标的平均值 |
| `overall_best_mse` | float or null | 所有攻击记录中最优（最小）的主指标值 |
| `overall_avg_exact_target_mse` | float or null | 对真实被攻击 batch / window 的平均重建误差 |
| `overall_avg_nearest_client_train_mse` | float or null | 对攻击客户端完整训练集最近样本的平均误差 |
| `overall_avg_psnr` | float or null | 平均 PSNR |
| `overall_avg_ssim` | float or null | 平均 SSIM |
| `overall_avg_gradient_mse` | float or null | 梯度/更新空间上的平均目标误差 |
| `overall_avg_objective_mse` | float or null | `overall_avg_gradient_mse` 的别名 |
| `overall_success_rate` | float | 全部攻击记录的成功率 |
| `overall_success_rate_percent` | float | 百分比形式的成功率 |
| `overall_passes` | bool | 整体成功率是否不高于 `success_rate_threshold` |
| `methods` | object | 各攻击方法（如 `DLG`、`iDLG`）的分组统计 |

`attack_summary.methods.<方法名>` 下每个字段含义如下：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `primary_metric` | string | 该攻击方法使用的主指标 |
| `target_type` | string or null | 该方法对应的攻击目标类型 |
| `success_count` | int | 成功攻击次数 |
| `total_count` | int | 总攻击次数 |
| `success_rate` | float | `success_count / total_count` |
| `success_rate_percent` | float | 百分比形式成功率 |
| `avg_mse` | float or null | 主指标平均值 |
| `best_mse` | float or null | 主指标最佳值 |
| `avg_exact_target_mse` | float or null | 对真实目标的平均重建误差 |
| `avg_nearest_client_train_mse` | float or null | 对最近训练样本的平均误差 |
| `avg_psnr` | float or null | 平均 PSNR |
| `avg_ssim` | float or null | 平均 SSIM |
| `best_ssim` | float or null | 最佳 SSIM |
| `avg_gradient_mse` | float or null | 平均目标函数误差 |
| `avg_objective_mse` | float or null | `avg_gradient_mse` 的别名 |
| `avg_time_seconds` | float or null | 平均单次攻击耗时 |
| `passes` | bool | 该方法成功率是否不高于阈值 |

## 四、`metrics.json`

### 1. 集中式训练下的 `metrics.json`

集中式 `metrics.json` 是一个对象。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `history` | list[object] | 按 epoch 保存的训练历史 |
| `test` | object | 最终测试指标 |
| `epochs` | int | 实际记录的 epoch 数 |
| `total_time_seconds` | float | 总耗时（秒） |

`history` 中每一项表示一个 epoch：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `epoch` | int | epoch 编号，从 0 开始 |
| `train_loss` | float | 将所有客户端数据集中后训练得到的平均训练损失 |
| `val_mse` | float | 验证集 MSE |
| `val_mae` | float | 验证集 MAE |
| `val_mape` | float | 验证集 MAPE |
| `epoch_time_seconds` | float | 该 epoch 的耗时 |
| `elapsed_time_seconds` | float | 从训练开始累计到当前的总耗时 |

### 2. 联邦 / gRPC 下的 `metrics.json`

联邦模式下，`metrics.json` 是一个列表，每一项对应一轮联邦训练的 `RoundRecord`。

#### Round 级字段

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `round` | int | 联邦轮次编号，从 0 开始 |
| `algorithm` | string | 当前联邦算法名，如 `fedavg`、`secure_quantized_fedavg` |
| `train_loss` | float | 当前轮各客户端本地训练损失的平均值 |
| `val_mse` | float | 当前轮聚合后全局模型的验证集 MSE |
| `val_mae` | float | 当前轮聚合后全局模型的验证集 MAE |
| `val_mape` | float | 当前轮聚合后全局模型的验证集 MAPE |
| `round_time_seconds` | float | 当前轮总耗时 |
| `elapsed_time_seconds` | float | 从训练开始累计到当前轮结束的耗时 |
| `model_parameters` | int | 当前全局模型参数个数 |
| `model_bytes` | int | 当前全局模型序列化后字节数 |
| `total_download_bytes` | int | 当前轮总参数下载字节数，等于 `total_parameter_download_bytes` |
| `total_download_parameters` | int | 当前轮总下载参数个数 |
| `total_upload_bytes` | int | 当前轮总参数上传字节数，等于 `total_parameter_upload_bytes` |
| `total_upload_parameters` | int | 当前轮总上传参数个数 |
| `total_parameter_download_bytes` | int | 仅模型参数本身的下载字节数总和 |
| `total_parameter_download_parameters` | int | 仅模型参数本身的下载参数个数总和 |
| `total_parameter_upload_bytes` | int | 仅模型参数本身的上传字节数总和 |
| `total_parameter_upload_parameters` | int | 仅模型参数本身的上传参数个数总和 |
| `total_parameter_bytes` | int | 当前轮参数上传 + 参数下载总字节数 |
| `total_transport_download_bytes` | int | 当前轮所有客户端实际 transport 下载总字节数 |
| `total_transport_upload_bytes` | int | 当前轮所有客户端实际 transport 上传总字节数 |
| `total_transport_bytes` | int | 当前轮 transport 上传 + 下载总字节数 |
| `total_transport_download_overhead_bytes` | int | 当前轮下载中除纯参数载荷外的额外开销 |
| `total_transport_upload_overhead_bytes` | int | 当前轮上传中除纯参数载荷外的额外开销 |
| `fedavg_reference_upload_bytes` | int | 若使用标准稠密 FedAvg 上传，本轮理论上传字节数 |
| `fedavg_reference_upload_parameters` | int | 若使用标准稠密 FedAvg 上传，本轮理论上传参数个数 |
| `fedavg_reference_total_bytes` | int | 若使用标准稠密 FedAvg，本轮理论上传 + 下载总字节数 |
| `upload_compression_ratio` | float | `fedavg_reference_upload_bytes / total_parameter_upload_bytes` |
| `total_communication_ratio` | float | `fedavg_reference_total_bytes / total_parameter_bytes` |
| `communication_ratio` | float | `upload_compression_ratio` 的别名 |
| `transport_upload_compression_ratio` | float | `fedavg_reference_upload_bytes / total_transport_upload_bytes` |
| `transport_total_communication_ratio` | float | `fedavg_reference_total_bytes / total_transport_bytes` |
| `clients` | list[object] | 当前轮每个客户端的通信与负载详情 |

#### `metrics.json[*].clients[*]` 中每个客户端字段

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `client_id` | string | 客户端名称，如 `Nd2O3` |
| `num_samples` | int | 当前客户端本地训练样本数，用于聚合加权 |
| `loss` | float | 当前客户端本地训练平均损失 |
| `payload_kind` | string | 当前客户端上传负载的语义类型 |
| `download_bytes` | int | 当前客户端参数下载字节数，等于 `parameter_download_bytes` |
| `download_parameters` | int | 当前客户端下载参数个数 |
| `parameter_download_bytes` | int | 纯模型参数下载字节数 |
| `parameter_download_parameters` | int | 纯模型参数下载个数 |
| `dense_download_reference_bytes` | int | 稠密 FedAvg 参考下载字节数 |
| `dense_download_reference_parameters` | int | 稠密 FedAvg 参考下载参数个数 |
| `upload_bytes` | int | 当前客户端参数上传字节数，等于 `parameter_upload_bytes` |
| `upload_parameters` | int | 当前客户端上传参数个数 |
| `parameter_upload_bytes` | int | 纯模型参数上传字节数 |
| `parameter_upload_parameters` | int | 纯模型参数上传个数 |
| `transport_download_bytes` | int | 当前客户端实际序列化下载字节数 |
| `transport_upload_bytes` | int | 当前客户端实际序列化上传字节数 |
| `transport_download_overhead_bytes` | int | 下载中超出纯参数载荷的额外开销 |
| `transport_upload_overhead_bytes` | int | 上传中超出纯参数载荷的额外开销 |
| `dense_upload_reference_bytes` | int | 稠密 FedAvg 参考上传字节数 |
| `dense_upload_reference_parameters` | int | 稠密 FedAvg 参考上传参数个数 |
| `compressor` | string | 压缩器或编码方式名称 |
| `privacy_clip_norm` | float | 上传前施加的 DP clip norm；`0.0` 表示未使用 |
| `privacy_noise_multiplier` | float | 上传前施加的 DP 噪声倍率；`0.0` 表示未使用 |
| `aggregation_weight` | float | 该客户端在服务器聚合时使用的权重 |

### 3. 常见 `payload_kind` 取值

| 取值 | 含义 |
| --- | --- |
| `dense_update` | 标准 FedAvg 稠密模型更新 |
| `quantized_update` | 量化后的稠密更新 |
| `sparse_update` | Top-k 稀疏更新 |
| `dp_topk_dp_update` | 经过裁剪/噪声处理后的 Top-k 稀疏更新 |
| `soteriafl_randomk_dp_update` | Random-k 形式的稀疏 DP 更新 |
| `fedpetuning_trainable_state` | 仅上传可训练 PEFT 参数 |

### 4. 常见 `compressor` 取值

| 取值 | 含义 |
| --- | --- |
| `none` | 无压缩 |
| `topk` | Top-k 稀疏化 |
| `topk_dp` | 带 DP 处理的 Top-k 稀疏化 |
| `randomk_unbiased` | Random-k 无偏稀疏压缩 |
| `float16_quantized_dense` | 稠密更新量化为 float16 |
| `int8_quantized_dense` | 稠密更新量化为 int8 |
| `trainable_subset` | 仅发送可训练参数子集 |

## 五、`attack_results.json`

`attack_results.json` 是一个列表，每一项对应一次攻击记录。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `name` | string | 攻击方法名称，通常为 `DLG` 或 `iDLG` |
| `mse` | float or null | 当前记录采用的主隐私指标值 |
| `reconstruction_mse` | float or null | `mse` 的兼容别名 |
| `psnr` | float or null | 重建结果的 PSNR |
| `ssim` | float or null | 重建结果的 SSIM |
| `iterations` | int | 攻击优化步数 |
| `time_seconds` | float | 本次攻击耗时 |
| `success` | bool | 在当前阈值下是否判定为攻击成功 |
| `success_threshold` | float | 用于判定成功的阈值 |
| `gradient_mse` | float or null | 梯度/更新空间上的目标误差 |
| `objective_mse` | float or null | `gradient_mse` 的别名 |
| `target_type` | string | 攻击目标类型，`gradient` 或 `update_payload` |
| `exact_target_mse` | float or null | 对真实被攻击 batch / window 的重建误差 |
| `nearest_client_train_mse` | float or null | 对攻击客户端完整训练集中最近样本的误差 |
| `nearest_client_train_indices` | list[int] or null | 最近训练样本索引 |
| `metric_name` | string | 当前记录采用的主指标名称 |

### `metric_name` 常见含义

| 取值 | 含义 |
| --- | --- |
| `reconstruction_mse` | 直接以对真实攻击目标的重建误差作为隐私指标 |
| `nearest_client_train_mse` | 以对攻击客户端完整训练集中最近样本的误差作为隐私指标 |

## 六、`config.yaml` / `config.json` / `config.toml`

这些文件保存的是实验最终实际生效的配置，已经包含：
- YAML include 展开
- 命令行 override 覆盖之后的结果

默认只保存 YAML；如果在 `artifacts.config_formats` 中指定了更多格式，则会额外保存 JSON 或 TOML。

这些文件主要用于：
- 精确复现实验
- 查看最终真实生效的超参数
- 不同实验之间做配置比对

## 七、`model.pt` 与 `centralized_model.pt`

| 文件 | 含义 |
| --- | --- |
| `model.pt` | 联邦训练最终全局模型的 state dict |
| `centralized_model.pt` | 集中式训练最终模型的 state dict |

## 八、使用建议

- 比较算法通信量时，优先使用 `total_parameter_*` 字段，因为它只反映模型参数本身的通信开销。
- 在 gRPC 模式下，`total_transport_*` 还包含协议开销、轮询控制流量、序列化包装等真实传输开销。
- 做最终结果对比时，优先看 `summary.json`。
- 画收敛曲线或分析每轮通信时，优先看 `metrics.json`。
- 做隐私/攻击分析时，优先看 `attack_results.json` 和 `summary.json` 中的 `attack_summary`。
